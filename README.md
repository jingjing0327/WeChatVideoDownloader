# WeChatVideoDownloader

#### 1、找到一个想下载的视频，点击分享按钮
![怎么用？](images/1724638792109.jpg)

#### 2、去找到并且选择“小米解解解”
![加我为好友](images/1724638792106.jpg)

#### 3、把视频转发给他
![加我为好友](images/1724638792104.jpg)

![加我为好友](images/Screenshot_2024-08-26-10-15-40-156_com.tencent.mm.jpg)
